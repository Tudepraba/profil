Tentang Saya

Halo, saya Tude Praba, Saya mahasiswa ITB STIKOM BALI yang berfokus pada Front End Web Developer. Saya senang membangun antarmuka website yang rapi, responsif, dan nyaman digunakan, serta selalu tertarik mempelajari teknologi baru di dunia web development.

Fokus saya adalah membuat desain web bersih dan fungsional, memastikan setiap halaman website tampil baik di berbagai perangkat. Saya terbuka untuk kolaborasi proyek freelance maupun full-time seputar pengembangan web front end.
